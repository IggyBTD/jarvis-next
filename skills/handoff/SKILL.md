---
name: handoff
description: End-of-session handoff: update the progress notes so the next session needs no chat history
---
Write the handoff for this session.

1. List what was built or changed this session (files and one line each) and what was checked, and where (real window, browser, unit tests). Say plainly what was not verified.
2. Open the project's progress notes (JARVIS_Progress.md in ".md Files", or the notes file the project instructions name) and update: current state, open items, unverified items, next steps, and one changelog entry.
3. Record any non-obvious decision and the reason for it.
4. Keep the style: direct, no filler, no emoji.
5. Finish with the two or three things the user should try first.
